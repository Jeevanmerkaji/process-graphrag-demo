# Interview transcript: physical prototype testing

*Synthetic, anonymised interview from a process analysis. Interviewer (I), Test Engineer (T).*

**I:** How does a test campaign start?

**T:** We get a Test Request from the design engineer, mostly by e-mail with the Requirements Specification attached. I then write the Test Plan: which tests, which prototype, which measurement equipment. Honestly, half of the test plan is copy-paste from earlier campaigns, if I can find them.

**I:** Who builds the prototypes?

**T:** The prototype workshop builds the Prototype Vehicle based on the Bill of Materials.

**I:** And then?

**T:** Then we run the tests on the test rig or on the proving ground. The Measurement Data is stored in the test data management system.

**I:** What happens after the test?

**T:** I analyse the Measurement Data and write the Test Report. That takes long. We have gigabytes of channel data and I look for anomalies more or less by eye.

**I:** And if a test fails?

**T:** Then I report the failure to the design engineer and they open a change request, so it goes into engineering change management. The Test Report is also needed for the quality gate and for the correlation with the simulation people.
